Important things

Public User Object

When users are shown, here is an example Object for it.

{
    "id": "1",
    "nickname": "Someone8448",
    "username": "someone8448",
    "bot": false,
    "rank": "owner",
    "online": true
}

Invite Object

When requesting the Invites as a administrator, here is the Objects

{
  "id": "MtsvNdiV6M",
  "guild": "1",
  "user": "1"
}

IDs

IDs are Numbers, but as Strings. It counts up, and their may be the same number for a user ID, a message ID, and a channel ID, etc... There are IDs for users, messages, channels, and guilds. Files and Invites use a Unique ID system.

Oh. And Guild = Server

Websocket

The WebSocket is on wss://chat.8448.space/ws . You send messages once it opens, and you send stringified Objects, there is an exception for file upload messages

Server-bound (Client -> Server)

Channel

This is data handled for a specific channel. The channel ID has to be a String of the Channel ID, and it has to be existant in a server you are in.

Join

Connect to a channel in a server you are in and have access to. You can join multiple channels per-socket.

{
  "m": "channel",
  "type": "join",
  "channel": "81",
  "chat": true
}

Set chat to true to receive the recent messages. channel is the Channel ID. You can not join that channel if you are already in it.

Leave

Leave that channel, and stop receiving messages from that channel.

{
  "m": "channel",
  "type": "leave",
  "channel": "81"
}

Get

Get the chat messages x chats up

{
  "m": "channel",
  "type": "get",
  "channel": "81",
  "chats": 100
}

You must be in this channel to get this data, though.

Send

Send a chat message in a channel

{
  "m": "channel",
  "type": "send",
  "channel": "81",
  "message": "Hello, World!"
}

You must be in the channel to send a message

Delete

Delete the channel from the server.

{
  "m": "channel",
  "type": "delete",
  "channel": "81"
}

This only works if the user is ADMIN or OWNER in the server

File

This is file uploading.

Create

Initialize the uploading for the file.

{
  "m": "file",
  "type": "create",
  "file": "txt",
  "size": 4096,
  "ft": "text/plain"
}

Done

To finish the upload, only do after you verified all the data is uploaded!

{
  "m": "file",
  "type": "done",
  "id": "file.txt"
}

Get

Request the file Object

{
  "m": "file",
  "type": "get",
  "id": "file.txt"
}

Data

Upload a chunk of the file.

{
  "m": "file",
  "type": "data",
  "id": "file.txt",
  "chunk": 0,
  "data": "Hello, World!"
}

In JSON, data can also be an array of bytes, or a normal String for normal text data

Data Binary message

This data is sent raw as Binary data to the websocket

Here is an array of bytes as an example in decimal

[
  117, // All file upload messages in binary start with this, it is 'u' in plain text
  8, // The length of the file name or file ID
  102, 105, 108, 101, 46, 116, 120, 116, //next eight bytes here are the file name, in text it is 'file.txt'. Real file names will be >64 bytes long though. Equivalent to id property in JSON message
  0, 0, 1, 0, //next four bytes make up a 32-bit integer. Here, it is 256. This number is equivalent of the JSON "chunk"
  72, 101, 108, 108, 111, 32, 87, 111, 114, 108, 100 //the rest of the data is the chunk of the file data.
]

Guild

These are different server-specific things

List

Request the list of guilds/servers you are in

{
  "m": "guild",
  "type": "list"
}

New

Create a new Guild/Server.

{
  "m": "guild",
  "type": "new",
  "name": "Testing Server"
}

New Channel

Create a new Channel.

{
  "m": "guild",
  "type": "new-channel",
  "id": "1",
  "name": "Silly Hello Chat"
}

Delete

Delete a server, server OWNER only though.

{
  "m": "guild",
  "type": "delete",
  "id": "1"
}

Channel

Get the channel list of a specific server.

{
  "m": "guild",
  "type": "channels",
  "id": "1"
}

Invite

Create an Invite to the guild/server

{
  "m": "guild",
  "type": "invite",
  "id": "1"
}

Join

Join a server with the Invite code

{
  "m": "guild",
  "type": "join",
  "invite": "wvuKgdhTMy"
}

Leave

Leave the server, you cannot leave as server owner

{
  "m": "guild",
  "type": "leave",
  "id": "1"
}

Kick / Ban

Kick or Ban a user from the server, admin or owner only

{
  "m": "guild",
  "id": "1", // guild id
  "type": "kick",
  "user": "1", // user id
  "perm": false // set to true to ban them, permanently.
}

Admin

As server owner, give or take admin

{
  "m": "guild",
  "id": "1", // guild id
  "type": "admin",
  "user": "1", // user id
  "give": true // if true, give admin, if false, take it away
}

DelInv (Delete Invite)

Delete an Invite as server admin or owner

{
  "m": "guild",
  "type": "delinv",
  "id": "1",
  "invite": "wvuKgdhTMy",
  "all": false // set to true to delete every invite, invite property is not needed here.
}

GetInv (Get Invite)

Get an Invite Code

{
  "m": "guild",
  "type": "getinv",
  "invite": "wvuKgdhTMy"
}

Login

User account management

On all of these, instead of using id property, you can use the name property with your username.

Create

Create an account

{
  "m": "login",
  "type": "create",
  "name": "helloworld",
  "pass": "1234567890"
}

Token

Log into an account with a token

{
  "m": "login",
  "type": "token",
  "id": "1",
  "token": "fb719254-5021-40da-954c-16d59f89cb02"
}

Pass

Log into an account with a password

{
  "m": "login",
  "type": "pass",
  "id": "1",
  "pass": "1234567890"
}

SetName

Set your display name, user name is a constant.

{
  "m": "login",
  "type": "setname",
  "pass": "1234567890",
  "name": "Hello World"
}

Reset

Change your password and reset your token

{
  "m": "login",
  "type": "reset",
  "old": "1234567890",
  "new": "helpmeineedanewpassword"
}

Ping

Send a ping message to the server, can be used for latency and time offset.

{
  "m": "ping",
  "e": 1745112909905 //can be whatever you want
}

User

Request users from the server

{
  "m": "user",
  "id": "1" //if no ID, then use name property with username.
}
